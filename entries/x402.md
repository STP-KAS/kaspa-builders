### README Now row "x402 dispatch" (whole row)

Bind the RC2 tag, not `main`. On the tag, `docs/versioning-policy.md` names four-byte **KCC-01** dispatch tags once, beside SilverScript `3ed9733`. The portable artifact reports compiler version `0.1.0`. That stamp is the known v1.0.0 compiler stamp. It does not flip KCC-1 to Final. Fixture entry tags are this covenant's own: escrow claim `23959b42`, topUp `ae09679c`, refund `17a2027b`; hash-chain borrow `c6e1d705`, ownerRotate `60104a23`, ownerSweep `89d59c06`. They are not the KCC-1 example vectors `2c49ed65` and `676b1a86`, and they are not KCC-20. The tag's template-id list omits `kaspa-x402-hash-chain-head-v1`. The same file's version paragraph and the contract include that id. [`cb769b17`](https://github.com/elldeeone/kaspa-x402/commit/cb769b171e6ee4f9c74577c014c3d00aa855053c) adds it to the list. `kaspa:mainnet` in that doc is a reserved profile name. The validation target is `kaspa:testnet-10`. npm `latest` stays on the earlier alpha. The four public packages are `1.0.0-rc.2` on the `rc` tag.
